# Processed Data Directory

This directory stores the processed metadata CSV (`labels.csv`) generated by `src/setup_dataset.py`.

The generated `labels.csv` contains:
- `image_path`: Relative path to the image file.
- `split`: Patient-level split designation (`train`, `val`, `test`).
- `Patient ID`: Anonymized patient identifier (guaranteeing zero patient overlap across splits).
- `Finding Labels`: Original radiological findings.
- One binary indicator column (0 or 1) for each selected abnormality.
